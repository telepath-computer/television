# Checklist template

The Checklist template makes an artifact that is a single list of things to tick off, laid out like a sheet of paper. Each story on this page is one state of its page; its markup and styles are the spec for that state. This page states the behaviour the stories cannot show.

<Canvas of={Stories.WithItems} />

## A new checklist

A new artifact from the template has the title "Checklist" and no items. The add field has the keyboard focus, so a person can start typing straight away.

<Canvas of={Stories.New} />

## The title

The title is edited in place: clicking it puts the caret in it, and the text saves as the person types. Return in the title adds a new, empty item at the top of the list and puts the caret in it, so typing a title and pressing Return goes straight to the first item. An empty item left without text is removed, as below. A title cleared to nothing shows "Untitled" in muted text until something is typed.

<Canvas of={Stories.Untitled} />

## Adding an item

Typing in the add field and pressing Return adds the text as a new item at the end of the list, not done, and clears the field, which keeps the focus for the next item. Return on an empty field does nothing.

<Canvas of={Stories.Adding} />

## Items

Clicking the box ticks or unticks an item. A done item stays where it is, its text muted and struck through. Clicking an item's text edits it in place, saving as the person types. Return ends editing and moves the focus to the add field. An item whose text is cleared and then left is removed.

<Canvas of={Stories.EditingItem} />

Each item's remove button appears when the pointer is over the item or it is being edited, and removes the item. Long items wrap, with the box beside their first line.

<Canvas of={Stories.LongItems} />

## A long list

The sheet grows with the list, and the page scrolls.
