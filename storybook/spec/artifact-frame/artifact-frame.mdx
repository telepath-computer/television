import { Meta, Canvas, Story } from "@storybook/addon-docs/blocks";
import { useEffect, useRef } from "react";
import * as Stories from "./artifact-frame.stories.ts";

export const HoverDemo = () => {
  const container = useRef(null);
  useEffect(() => {
    const timer = window.setInterval(() => {
      container.current?.querySelector(".artifact-frame")?.toggleAttribute("data-hovered");
    }, 2000);
    return () => window.clearInterval(timer);
  }, []);
  return <div ref={container} className="artifact-frame-hover-demo"><Story of={Stories.TransparentAtRest} inline /></div>;
};

<Meta of={Stories} name="Spec" />

# Artifact frame: transparency

These stories and [styles](./styles.css) specify the transparent state promised by the [product spec](../../../specs/product/artifacts.md#^af-transparent). The opaque story supplies a comparison; the [frame spec](../../../specs/ui/app/artifact-frame/index.md) owns the rest of the frame.

<Canvas of={Stories.Opaque} />

<Canvas of={Stories.TransparentAtRest} />

Hovering the transparent frame reveals the frost and title bar; leaving hides them. Both fade over 300ms with ease timing. The bar overlays the bottom of the document without resizing it, and becomes hidden after fading out so its controls leave keyboard navigation. While the frame's menu is open, the frame keeps its hovered state even after the pointer leaves, so the menu never fades with the bar. Reduced motion makes the change immediate.

<Canvas of={Stories.TransparentHovered} />

The hovered story forces the pointer state with `data-hovered`; moving the pointer over the resting story produces the same result.

This demonstration alternates between rest and hover every two seconds, using the same fade. Pointer hover still works.
