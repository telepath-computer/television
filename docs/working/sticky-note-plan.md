### Verification criteria and risks

1. **Shipped contents:** exact identity/version/minimum, empty seed, transparent 360 × 360 display with the shared full-screen default, byte-identical font, and a transparent PNG of `WithText`. Server and CLI outputs preserve the whole source tree. Both IDs install independently and retain the specified state across failure/retry. Real packed CLI and source notices contain complete attribution; review also checks the thumbnail and README meaning.
2. **Save decisions:** validate the whole root; subscribe there and save only `text`. Controlled-clock contracts prove the 400 ms reset, blur trigger, acknowledgement ownership, invalid-data guard, and reconnect decisions. Keep retained text distinct from the SDK value and distinguish an unsent edit from a sent, unconfirmed edit. A delayed confirmation must not clear newer typing. A disconnect must retain the latest draft through SDK rollback; confirmed access loss, unreadable data, or a non-disconnection refusal must discard it as specified. Reconnect must finish fresh access/root checks before sending. Checklist clears access on disconnect, so copying its `canWrite`/reconnect behavior would be wrong here.
3. **Real behavior:** the installed template is created through the popover and runs in the real sandbox. Prove pause and blur saves, scoped writes, native multiline/plain-text paste, selection/copy/undo, two writers and spawned agent commands, loading, changed/revoked access, offline drafts and their loss on reload/close, refused saves, invalid data, damaged-file recovery, and scrolling. Carry the architecture seam observations in these walks where the proofs allow it. Proxy observations alone cannot detect SDK calls rejected locally while disconnected; pair them with the production-model operation recorder and permitted SDK/DOM observation. Hold real traffic without fabricating replies. Treat the selective access-notification hold as the declared message-order mock. Sent writes may have uncertain outcomes; draft-lifetime cases use wholly unsent offline text.
4. **Rendered states:** compare all 16 exports, including unembedded stories, with the complete `.sticky-note-page` root at matching viewport/theme/appearance. Fail if a story has no production setup. Await both Caveat fonts and completed story `play`; reach production focus/caret/scroll states through real input. Use no production style/markup additions or permitted differences. Keep real motion for conformance; behavior tests may use the declared CSS-motion override. Native textarea value updates must preserve selection, scrolling, and undo when the displayed value is unchanged. Establish status regions before updating their message; normal saving stays silent.
