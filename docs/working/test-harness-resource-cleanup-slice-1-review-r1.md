## Refinements (none blocking)

1. **One contract clause is proven by the seam, not the contract.** `^testing-t-build-lifetime` says "Per-case server disposal cannot invalidate the worker's reusable build", but `test/repo/worker-builds.test.ts` has no server; the fixture body of the seam proves it (shared outputs present after `server.dispose()`). Move the sentence to `^testing-t-build-worker-seam`, or cite the seam for it. Proof-only.
2. **The seam runs each framework twice; once would prove the same.** The second nested run exists to show "a later worker owns a separate lifetime", but its separate paths follow from its private `TMPDIR`, and the lifetime claim that matters, nothing left after teardown, is proven by the first run. Dropping the loop halves four source-CLI builds and four Vite builds per execution of this test. Optional; the plan accepted a real build and the surface is remote-only.
3. **One line in the record for the last static log.** `38976455.log` ends with the stopped fetch's stack trace, which a reader opening it cold could take for a static-check failure. The record already explains the event in prose; a clause pointing at it next to "Static logs are retained" would save the reader the inference.
