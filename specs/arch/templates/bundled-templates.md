# Bundled artifact template

Television ships the Checklist [artifact template](../../product/templates.md#^artifact-template-bundled). It follows the ordinary [folder and copy contract](./index.md#^artifact-template-package); [bundled installation](./bundled-installation.md) owns when an installed copy is kept or replaced. The [Checklist UI spec](../../ui/templates/checklist/index.md) owns the page's interaction, markup, and styling.

| Folder ID | Manifest `name` | Manifest `description` | Initial `version` | Minimum installed version |
|---|---|---|---|---|
| `checklist` | Checklist | A list of items to tick off and edit. | `1.0.0` | `1.0.0` |

The bundled manifest declares `display: { "width": 640, "height": 800 }` in reference pixels. `fullScreen` uses the shared default. `BUNDLED_ARTIFACT_TEMPLATE_IDS` is the readonly tuple `['checklist']`; [telemetry](../telemetry/derivation.md#^artifact-template-telemetry-derivation) uses this closed vocabulary. ^bundled-artifact-template-inventory

## Store

The template's `data.json` seeds the artifact's [own JSON store](../../product/resources/resources.md#^rs-own-store) with `{"title":"Checklist","items":{}}`. The value has this contract because agents write it:

```ts
interface ChecklistData {
  title: string;
  items: Record<string, {
    order: number;
    text: string;
    done: boolean;
  }>;
}
```

Each item key is generated by [JSON store `push`](../resources/json-store.md#^js-arch-push-keys). The page displays items by ascending `order`, breaking ties by key. `order` permits insertion at the top or directly below an item without replacing the list. The page subscribes to the store through the [resource SDK](../resources/sdk.md). It writes title changes only at `title` and each item change only at `items/<key>` or a path below that item. It adds an item with its `order` by `push` under `items`, and removes only that item's key when the item is deleted. The page uses the SDK's [`getAccess` and `onAccessChanged`](../resources/sdk.md#^sdk-access) to follow changes in write access. The [UI pilot](../../ui/templates/checklist/index.md) owns how these changes appear and how editing works. ^bundled-artifact-template-checklist-store

## Packaged page and guidance

The page loads Television's canonical stylesheet and the resource SDK, and includes its other page dependencies inside the template folder so copied artifacts work independently. Its `thumbnail.png` is a 4:5 portrait screenshot, about 400 by 500 pixels, of the UI pilot's `WithItems` state, approved by Rupert. The [Templates popover UI spec](../../ui/app/skill-selector/index.md) owns how the image is displayed. ^bundled-artifact-template-checklist-page

The bundled `README.md` explains the `title` string and the `items` map, including each item's numeric `order`, `text` string and `done` boolean. It tells an adapting agent to change the title at `title`, add items with `tv resource json push` under `items` while supplying an `order`, and change or remove an item at its own path with `tv resource json` so an edit does not replace other items. It explains that the page and agent share the artifact's own store and that changes appear live. ^bundled-artifact-template-checklist-readme
