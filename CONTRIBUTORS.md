# Contributing

Television's code is available under the [MIT license](LICENSE). You're welcome to fork it, build it, and modify it under those terms.

We're not accepting pull requests from outside contributors at the moment. Television uses a spec-driven development process that we haven't opened to outside contributors yet.

We plan to open up to contributions later and will update this file when we do.

If you're interested in contributing, please join our Discord! We'd love to chat!
