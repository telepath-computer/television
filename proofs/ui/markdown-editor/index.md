# Markdown editor color (UI) — proof

Proves [specs/ui/markdown-editor/index.md](../../../specs/ui/markdown-editor/index.md).

## Coverage model

This is a stylesheet-only surface. Its one automated assertion proves the complete production crossing: discovery of this standalone UI-spec directory, byte identity, source import order, route inventory, and inclusion in a fresh Markdown-view build. It reads the real repository files and runs the real Vite builder without mocks or test hooks. The shared [foundation crossing](../../arch/ui/foundation.md#^ui-t-foundation-copy) carries registry completeness and byte identity, while the shared [document-route contract](../../arch/ui/index.md#^ui-t-style-delivery) carries source wiring; this proof adds no duplicate scans. Together with the fresh-build check, they prove that the authoritative sheet reaches the shipped document after the implementation-owned layout sheet. They do not claim that a browser applies each declaration or that the resulting colors are visually successful.

Exact styling remains stylesheet authority under the [UI testing policy](../../../specs/arch/testing-policy.md#^ui-styling-out). Under the [TV-649 release exception](../../../specs/arch/ui/conformance.md#release-exception-for-tv-649), implementation and visual review judge the complete [color-state promise](../../../specs/ui/markdown-editor/index.md#^md-editor-color-states) across representative light, dark, and themed appearances. The themed set includes a purpose-built light-primary contrast theme so the active outside table-header handle exercises `--color-primary-text` against a light `--color-primary` fill. The same judgment covers the rendered and source-reveal states, retained CodeMirror focus geometry, task controls, and the table’s open menu. The opt-in browser fixture at `packages/view-markdown/test/e2e/visual-review.spec.ts` makes those exact poses reproducible and can write screenshots plus a computed-style inventory for human inspection. Its checks establish only that the requested interaction states were reached; they do not turn visual success into an automated color, screenshot, or selector assertion. Existing browser probes for cursor and earlier marker token mappings remain regression evidence under the exception, but they do not substitute for that review or enumerate the stylesheet.

The real-browser [artifact-color acceptance](../../arch/themes/delivery.md#^theme-delivery-t-artifact-colors) proves that canonical and active-theme values reach a built Markdown document and update live. This proof composes with that delivery evidence rather than repeating theme selection or native `color-scheme` coverage. Server-rendered read-only Markdown remains outside this proof and has no parity assertion against the editor sheet.
