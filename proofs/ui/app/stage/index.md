*How the promises in Stage (UI) are proven.*

# Stage (UI) — proof

Proves [specs/ui/app/stage/index.md](../../../../specs/ui/app/stage/index.md).

## Coverage model

The production Stage is exercised at its application-service boundary: authored channel/page state and documents are fixtures, and the service mock records operations while product proofs retain transport and shared-state outcomes. Browser contracts cover selection, sizing, full-screen, menu priority over resize handles, drag termination, and coupled reorder motion; the memory contract observes discarded views after channel replacement. The reordered-pickup regression now observes unchanged rendered page boxes, alongside retained displacement and persistence checks. A Node contract test compares the production default page size with the stage's authored initial size; the layout, onboarding-installer, and migration proofs prove that a page created with a new artifact, an onboarding page without an authored size, and a stored page backfilled at boot each receive that default.

### Initial page size

- **Contract** (the producer side of the handoff from the shared default page size, `DEFAULT_PAGE_SIZE` in the shared package, to the server paths that give a page its starting size; the test reads [ui/app/stage/measures.yml](../../../../specs/ui/app/stage/measures.yml) when it runs and restates no value; no mocks, fixtures, or test hooks): the shared default page size is [measures.yml#page.initial_width_px](../../../../specs/ui/app/stage/measures.yml#page.initial_width_px) by [measures.yml#page.initial_height_px](../../../../specs/ui/app/stage/measures.yml#page.initial_height_px) reference pixels, which [the stage spec](../../../../specs/ui/app/stage/index.md#the-size) makes the starting size of a page created without an authored size — *(covered by `test/repo/ui-measure-crossings.test.ts` “production page-sizing measure crossings > stage constants equal the authoritative sizing, handle, and snap measures”)*. ^st-ac-initial-size

Coverage relationship: each server path that gives a page its starting size reads this shared default, and the path's owning proof exercises it on the real code path: [arch/layout/index.md#^ly-ac-create-appends](../../../arch/layout/index.md#^ly-ac-create-appends) for the page a new artifact appends, [arch/onboarding/installer.md#^t-layout-install](../../../arch/onboarding/installer.md#^t-layout-install) for an onboarding page, which takes its configured size or, without one, this default, and [arch/layout/migration.md#^t-size-backfill](../../../arch/layout/migration.md#^t-size-backfill) for a stored page backfilled at boot. Those tests compare against the shared default rather than its numbers, so together with this contract they cover a change to the authored initial size without repeating its value in another test.
