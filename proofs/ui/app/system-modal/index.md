## Coverage model

The gate may be connected and authenticated while blocking use of the server. A small state/context table proves the dialog's salient contents and local-only action. It poses state and records the disconnect callback, so it forfeits state selection, live retry timing and connection effects. The [app proof](../index.md#^ap-ac-one-state) owns served-state priority and real-browser recovery; [desktop connection coverage](../../../arch/desktop/connect-flow.md) owns saved startup and the [product walk](../../../product/desktop-app.md#^desktop-ac-saved-auth) crosses the local button into real deletion and setup.

A real-browser contract proves that Escape and backdrop input leave the production connection dialog open. It shares native dialog mechanics with the [dialog proof](../dialog/index.md), which still owns ordinary dismissal, focus containment and background inertness. The [gate proof](../desktop-upgrade-gate/index.md) owns gate contents, restart and its dismissal exception. The app owns routing into the gate; its [real reconnect walk](../index.md#^ap-ac-gate-uncovered) proves that the gate replaces the connection dialog without stacking.

The drag seam uses real Electron hit testing and movement while a modal occupies the top layer, on both the local page and the served gate. The X11 driver substitutes the host window manager, as declared below; no automated Mac movement claim is made. The 36px measure, typography, colours and panel geometry remain styling authority under conformance and review. The state table requests authored icons and their spinning state; the [icon proof](../../foundation/icons/index.md) owns glyphs and spinner motion.

## Test hooks

View contracts may supply state and a recording disconnect callback at the production view boundary; production obtains them from the served application or local connection owner. These are mocks of those owners, not alternate production states.

The served drag route uses the update runtime’s simulation and test-mode restart recording, as declared by [desktop update coverage](../../../arch/desktop/updates.md#test-hooks), to provide an actionable dialog button. Native pointer hit testing and window movement remain real; an actual downloaded update and runtime restart are outside this drag claim.

The Electron seam uses [desktop harness hooks](../../../arch/desktop/connect-flow.md#test-hooks) and the [required-version hook](../../../arch/updates/desktop-upgrade-gate.md#^hook-required-version) to reach the served gate.
