## Assertions

### Acceptance criteria

Coverage is organized around user outcomes rather than repeating the history-engine, frame-control, and route contracts beneath them ([arch/testing-policy.md#^spec-purposes](../../specs/arch/testing-policy.md#^spec-purposes)). A cited neighboring assertion remains its owner's test.

Shared declaration: these tests may use the testing policy's default motion override because none claims transition or animation behavior. That mock forfeits frame and stage motion to their UI owners; navigation state, frame loading, browser or webview delivery, persistence, and the stated user input remain real. A case that names no other mock or hook uses none.

- **Acceptance** (outer boundaries: a real browser and the real Electron app, each against a really-running server; temporary multi-page path or URL artifacts are fixtures; the Electron fixture-launch hook selects the app URL and replaces no navigation mechanism): Back walks to each earlier page in the artifact's history on both the browser iframe and Electron webview paths — *(covered by inherited tests: `packages/web/test/e2e/artifact-navigation.01.test.ts` "clicking relative links records history and host back restores earlier pages" and `packages/desktop/test/e2e/artifact-navigation.test.ts` "records same-origin webview navigations and host back returns to canonical without duplicates")*. ^ac-back
- **Acceptance** (outer boundary: a real browser against a really-running server; a temporary multi-page path artifact seeded in the real `ServerStore` is the fixture; no additional mocks or test hooks): after Back moves away from the history tail, Forward walks the remembered pages in order until it reaches that tail — *(covered by test: `packages/web/test/e2e/artifact-navigation.01.test.ts` "clicking relative links records history and host back restores earlier pages", in the same browser walk as [#^ac-back](#^ac-back))*. ^ac-forward
- **Acceptance** (outer boundary: a real browser against a really-running product server; a temporary four-page path artifact created through the production API is the fixture; no additional mocks or test hooks): after Back, following a different link removes the abandoned forward entries and leaves the new destination as the history tail — *(covered by inherited test: `packages/web/test/e2e/navigable-history-real-stack.01.test.ts` "back then new browser iframe navigation clears forward history entries")*. ^ac-forward-truncation
- **Acceptance** (outer boundaries: a real browser and the real Electron app against really-running product servers; temporary multi-page path artifacts and a second browser channel are fixtures created through production APIs; the Electron fixture-launch hook only selects the app URL): browser reload, channel teardown and return, and desktop quit and relaunch each restore the artifact's current page; the persisted entries and cursor remain the same history used by Back and Forward — *(covered by inherited tests: `packages/web/test/e2e/navigable-history-real-stack.01.test.ts` "path artifact history works through the real product server and browser iframe" and `packages/web/test/e2e/navigable-history-real-stack.02.test.ts` "channel switch preserves browser iframe navigation state", minimally reworked to select channels through the redesigned channel sidebar, plus `packages/desktop/test/e2e/all-webview-dispatcher.02.test.ts` "quit and relaunch restores path webview navigation history")*. ^ac-persisted
- **Acceptance** (outer boundaries: a real browser and the real Electron app against really-running servers; temporary multi-page path or URL artifacts are fixtures; the Electron fixture-launch hook only selects the app URL): returning to the canonical page places the history cursor at home without appending that page or duplicating an existing entry — *(covered by inherited tests: `packages/web/test/e2e/artifact-navigation.02.test.ts` "clicking a link back to canonical resets the cursor without storing canonical" and `packages/desktop/test/e2e/artifact-navigation.test.ts` "records same-origin webview navigations and host back returns to canonical without duplicates")*. ^ac-back-to-home
- **Acceptance** (outer boundaries: a real browser and the real Electron app against really-running product servers; temporary path and URL artifacts plus a local external HTTP destination are fixtures; the Electron fixture-launch hook only selects the app URL): a normal external-link click stays on the artifact's in-frame navigation path — the browser shows the unsupported page and Back returns internally, while Electron loads the destination in the webview and Back returns to the prior page — *(covered by inherited tests: `packages/web/test/e2e/navigable-history-real-stack.02.test.ts` "external browser navigation uses the real unsupported view and host history" and `packages/desktop/test/e2e/artifact-navigation-external.test.ts` "records navigation to a different external site and host back returns to the previous page")*. ^ac-external-normal
- **Acceptance** (outer boundary: a real browser against a really-running server; temporary HTML and markdown path artifacts with external links are fixtures; the markdown shell is the checked-in view document running its production module; no additional mocks or test hooks): Cmd/Ctrl-click opens the external destination in another browser page while the artifact remains on its current page with unchanged history — *(covered by inherited tests: `packages/web/test/e2e/artifact-navigation.02.test.ts` "modifier-click opens a new tab and leaves iframe history unchanged" and "markdown modifier-click opens a tab and leaves artifact history unchanged")*. ^ac-external
- **Seam** (webview modifier-click → desktop external-open dispatcher, crossed in the real Electron app against a really-running server; temporary path, URL, and markdown artifacts are fixtures; the fixture-launch hook selects the app URL, and `TV_TEST_MODE` captures the external-open target instead of launching an operating-system browser, forfeiting only that final operating-system action to Electron's `shell.openExternal` contract): each renderer sends the external target to the dispatcher and leaves its webview URL and artifact history unchanged — *(covered by tests: `packages/desktop/test/e2e/all-webview-dispatcher.01.test.ts` "path artifact renders in a webview, records internal navigation, supports back, and routes Cmd/Ctrl-click externally" and "URL artifact Cmd/Ctrl-click opens externally without changing webview history", plus `packages/desktop/test/e2e/all-webview-dispatcher.02.test.ts` "markdown Cmd/Ctrl-click opens an external link without navigating the webview", composed with `packages/desktop/test/main.test.ts` "routes webContents window-open URLs to shell.openExternal")*. ^ac-external-electron
- **Acceptance** (outer boundary: a real browser on the Linux CI host against a running product server; temporary HTML and markdown path artifacts, an isolated browser profile, virtual display, and a temporary host-registered `example-app:` handler are fixtures; the profile records the user's prior approval for each fixture origin, with no navigation, browser, or handler mock): plain, Ctrl-, Meta-, and middle-click in each artifact reach the registered handler, leave the artifact document and history unchanged, make no popup request, and create no stray browser page. Ctrl and Meta exercise both modifier event branches on Linux; this is not a claim of macOS runtime coverage. A markdown `javascript:` link has no effect, while an HTML `javascript:` link acts only in its own artifact context and is never recorded or handed to the host operating system — *(covered by test: `packages/web/test/e2e/artifact-navigation.02.test.ts` "application-link activations cross the real Linux browser handler without popups")*. ^ac-application-links-browser
- **Acceptance** (outer boundary: the real Electron app on the Linux CI host against a running product server; temporary HTML and markdown path artifacts and a temporary host-registered `example-app:` handler are fixtures; the fixture-launch hook selects the app URL and no handoff mechanism is mocked): real left- and middle-button activation in each artifact reaches the registered handler, leaves the webview URL and artifact history unchanged, and creates no extra Electron window — *(covered by tests: `packages/desktop/test/e2e/all-webview-dispatcher.01.test.ts` "HTML application links cross the real Linux operating-system handler" and `packages/desktop/test/e2e/all-webview-dispatcher.02.test.ts` "markdown application links cross the real Linux operating-system handler")*. ^ac-application-links-electron
- **Seam** (trusted webview input → preload gesture gate → main-process external-open dispatcher, crossed in the real Electron app; temporary local HTML and markdown artifacts plus a third-party URL artifact are fixtures, and `TV_TEST_MODE` captures the target instead of invoking `shell.openExternal`, forfeiting only the final operating-system action to [#^ac-application-links-electron](#^ac-application-links-electron)): a request without active user activation, direct custom-scheme navigation/window-open, `javascript:`, local-resource values, and requests from a third-party URL artifact do not cross the seam. During real activation, executable local HTML may choose the application URL in its own event handler; the gesture gate does not require the URL to come from the activated element. Existing browser-local behavior remains within the webview — *(covered by tests: `packages/desktop/test/e2e/all-webview-dispatcher.01.test.ts` "local HTML application handoff requires activation and preserves subframes" and "third-party URL artifacts cannot request application handoff", plus `packages/desktop/test/e2e/all-webview-dispatcher.02.test.ts` "markdown application links require real user activation and leave navigation unchanged")*. ^ac-application-link-gesture-electron

The history engine's inherited contracts prove home state, Back and Forward predicates and transitions, forward-tail truncation, mutation persistence, hydration, pruning, and URL conversion at [arch/artifact-frame/reload-navigation.md#^rn-ac-home](../arch/artifact-frame/reload-navigation.md#^rn-ac-home), [arch/artifact-frame/reload-navigation.md#^rn-ac-back-forward](../arch/artifact-frame/reload-navigation.md#^rn-ac-back-forward), [arch/artifact-frame/reload-navigation.md#^rn-ac-forward-truncation](../arch/artifact-frame/reload-navigation.md#^rn-ac-forward-truncation), [arch/artifact-frame/reload-navigation.md#^rn-ac-mutations](../arch/artifact-frame/reload-navigation.md#^rn-ac-mutations), [arch/artifact-frame/reload-navigation.md#^rn-ac-hydration](../arch/artifact-frame/reload-navigation.md#^rn-ac-hydration), [arch/artifact-frame/reload-navigation.md#^rn-ac-prune](../arch/artifact-frame/reload-navigation.md#^rn-ac-prune), and [arch/artifact-frame/reload-navigation.md#^rn-ac-convert-url](../arch/artifact-frame/reload-navigation.md#^rn-ac-convert-url). Its browser and Electron route contracts and real handoffs compose the platform breadth without another Forward launch. The frame UI owns when Back and Forward appear, their enabled states and component interaction ([ui/app/artifact-frame/index.md](../../specs/ui/app/artifact-frame/index.md)); these product assertions own the browser-like outcomes, not a second component matrix. In [#^ac-persisted](#^ac-persisted), selecting another channel and returning is fixture action through the redesigned channel sidebar: [ui/app/sidebar/index.md](../../specs/ui/app/sidebar/index.md) owns the row mechanics, while this assertion observes only the artifact history after return.

Coverage relationship: the browser demo mode exception under [Navigable artifacts](../../specs/product/artifact-navigation.md#navigable-artifacts) — no history and no remembered place for an external page artifact a browser shows in demo mode — is walked by [product/artifacts.md#^af-ac-demo-mode](./artifacts.md#^af-ac-demo-mode) and [product/artifacts.md#^af-ac-demo-return](./artifacts.md#^af-ac-demo-return), which observe Back and Forward absent after in-page navigation and the artifact's own URL after a channel switch. This proof orders no duplicate walk.
