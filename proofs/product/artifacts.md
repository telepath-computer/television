# Artifacts — proof

Proves [specs/product/artifacts.md](../../specs/product/artifacts.md).

## Coverage model

Coverage declarations are carried inside the migrated assertion blocks below.

## Test hooks

- **Server operating-system home directory.** Browser demo mode acceptance launches the real `tv serve` process with `HOME` set to a temporary directory, so creating or deleting `.tv-mozfest-demo` there turns [browser demo mode](../../specs/product/artifacts.md#^af-demo-mode) on or off. The server's [Television home](../../specs/product/cli.md#^cli-home) is a separate temporary directory given with `--home`. The same launch pins `TELEVISION_DEVELOPER_HOME` to the invoking user's operating-system home directory so telemetry project routing is unchanged. Production reads the operating-system home directory of the user running the server.

## Assertions

### Acceptance criteria

Coverage is organized around product outcomes rather than restating the frame-core, bridge, reload, stage, and UI contracts beneath them ([arch/testing-policy.md#^spec-purposes](../../specs/arch/testing-policy.md#^spec-purposes)). A cited neighboring assertion remains its owner's test; this section adds no second walk over the same path.

Shared declaration: these acceptance cases may use the testing policy's default motion override because none claims transition or animation behavior. That mock forfeits only motion to the owning UI and stage assertions; every other production mechanism on the stated path remains real. An assertion that names no additional mock or hook uses none.

- **Acceptance** (outer boundary: a real browser against a really-running server; three path artifacts and their temporary files are fixtures created through the production API; no additional mocks or test hooks): invoking Delete from the frame menu presents a confirmation naming the artifact; declining leaves the artifact, tab, page, and file unchanged; invoking Delete again and confirming removes the artifact from the channel and removes its tab and frame while the file remains on disk — *(covered by test: `packages/web/test/e2e/artifact-view-wheel.test.ts` "frame menu deletion cancels safely then removes the artifact, tab, and page without deleting its file (^af-ac-delete)")*. ^af-ac-delete
- **Acceptance** (outer boundary: a real browser against a really-running server; an oversized raw image, a PDF, and HTML whose content-security policy blocks Television's inline script while allowing the fixture's same-origin external script are temporary artifacts created through the production API; no additional mocks or test hooks): each artifact renders on its selected page and accepts an observable native pointer action appropriate to its document — scrolling the raw image and PDF, and clicking a control whose external script updates the CSP-blocked page — *(covered by test: `packages/web/test/e2e/artifact-view-wheel.test.ts` "keeps raw image, PDF, and CSP-blocked documents natively interactive without bridge readiness (^af-ac-native)")*. ^af-ac-native
- **Acceptance** (outer boundaries: a real browser and the real Electron app against a really-running server, one platform case each; two HTML artifacts on separate tab pages are authored fixtures, and the Electron fixture-launch hook only selects the app URL; no additional mocks): after the user types into, scrolls, and starts a counter in one document, switching to the other tab and back preserves the first document's value, scroll position, and running state without a reload — *(browser case covered by test: `packages/web/test/e2e/artifact-view-wheel.test.ts` "preserves typed, scrolled, and running iframe state through a tab switch without another load (^af-ac-tab-continuity)"; Electron case covered by test: `packages/desktop/test/e2e/artifact-view-webview-wheel.test.ts` "preserves typed, scrolled, and running webview state through a tab switch without another load (^af-ac-tab-continuity)")*. ^af-ac-tab-continuity
- **Acceptance** (outer boundaries: a real browser and the real Electron app against a really-running server, one platform case each; a temporary folder artifact whose index loads a stylesheet from a subdirectory beneath the artifact root is created through the production API, and the Electron fixture-launch hook only selects the app URL; no additional mocks): changing only that subdirectory stylesheet updates the loaded artifact's computed presentation without an index edit or manual reload — *(covered by tests: `packages/web/test/e2e/path-artifact-real-stack-coverage.test.ts` "reloads a folder artifact when a subdirectory stylesheet changes (^af-ac-folder-source)" and `packages/desktop/test/e2e/path-webview-content-reload.test.ts` "reloads a folder artifact when a subdirectory stylesheet changes (^af-ac-folder-source)")*. ^af-ac-folder-source
- **Acceptance** (outer boundary: a real browser against a really-running server; a temporary HTML path artifact created through the production API, authored with shell and artifact selectors and custom properties that deliberately conflict; no additional mocks or test hooks): the shell keeps its production styling and the artifact keeps its authored styling, with neither side's declarations affecting the other — *(covered by test: `packages/web/test/e2e/artifact-view-wheel.test.ts` "keeps the visible and accessible artifact names equal while isolating shell and document styles (^af-ac-title, ^af-ac-isolation)")*. ^af-ac-isolation
- **Acceptance** (same fixture, boundary, and walk as [#^af-ac-isolation](#^af-ac-isolation)): the title supplied at creation renders verbatim as both the visible frame name and the document's accessible name — *(covered by test: `packages/web/test/e2e/artifact-view-wheel.test.ts` "keeps the visible and accessible artifact names equal while isolating shell and document styles (^af-ac-title, ^af-ac-isolation)")*. ^af-ac-title

Coverage relationship: the root `data-theme` override for Television-managed HTML under [the document contract](../../specs/product/artifacts.md#^af-native-interaction) is carried in Chromium by [theme delivery's artifact appearance assertion](../arch/themes/delivery.md#^theme-delivery-t-artifact-colors), whose real-browser HTML and Markdown artifacts observe exact light and dark marker values, and in Electron by [desktop appearance](../arch/desktop/appearance.md#^desktop-appearance-t-electron), whose real managed artifact webview observes the same marker through appearance changes without reloading. This proof orders no duplicate artifact-appearance walk.

Coverage relationship: the optional `authoredForAppVersion` query under [the document contract](../../specs/product/artifacts.md#the-document) is carried by [canonical wrapper query propagation](../arch/themes/delivery.md#^theme-delivery-t-wrapper-query), which includes the advisory query and copies it exactly to every import. [Imported-resource query neutrality](../arch/themes/delivery.md#^theme-delivery-t-import-query) proves that the query changes neither bytes nor validators, while the [frozen](../arch/themes/delivery.md#^theme-delivery-t-frozen-canonical) and [live](../arch/themes/delivery.md#^theme-delivery-t-canonical) query-free assertions prove that omitting it remains valid. This proof orders no duplicate canonical-delivery test.

Coverage relationship: the shared-artifact outage outcomes under [#^af-shared-offline](../../specs/product/artifacts.md#^af-shared-offline) are carried by the bridge's declared network. [arch/artifact-frame/artifact-bridge.md#^ab-ac-offline-browser](../arch/artifact-frame/artifact-bridge.md#^ab-ac-offline-browser) and [arch/artifact-frame/artifact-bridge.md#^ab-ac-offline-electron](../arch/artifact-frame/artifact-bridge.md#^ab-ac-offline-electron) walk last-seen content and recovery in a real browser and the real Electron app. The platform-specific raw-document and CSP-limited outcomes are [arch/artifact-frame/artifact-bridge.md#^ab-ac-offline-raw-browser](../arch/artifact-frame/artifact-bridge.md#^ab-ac-offline-raw-browser), [arch/artifact-frame/artifact-bridge.md#^ab-ac-offline-csp-browser](../arch/artifact-frame/artifact-bridge.md#^ab-ac-offline-csp-browser), [arch/artifact-frame/artifact-bridge.md#^ab-ac-offline-csp-electron](../arch/artifact-frame/artifact-bridge.md#^ab-ac-offline-csp-electron), and [arch/artifact-frame/artifact-bridge.md#^ab-ac-offline-raw-electron](../arch/artifact-frame/artifact-bridge.md#^ab-ac-offline-raw-electron). This spec orders no duplicate outage test. ^af-ac-offline

- **Contract** (the server's artifact ID generator and its artifact update route, run in process over temporary storage; no mocks): every generated ID carries 80 bits beyond any time component, 10,000 generated IDs are distinct, IDs generated within one millisecond share no random part, and an artifact updated through the update route keeps its ID. That the bits come from a cryptographic source is checked in review of the generator, because no test can tell a cryptographic source from a good non-cryptographic one. This proves the generated-ID half of [the ID](../../specs/product/artifacts.md#^af-artifact-id) — *(policy-grade tests: `packages/server/test/artifact-ids.test.ts`, all four cases)*. ^af-ac-artifact-id

Coverage relationship: serving an artifact's content at `/artifact/<id>/` to a browser without the server's token, and the store that knowing its ID reaches, are walked by [the resources page acceptance](./resources/resources.md#^rs-ac-page-spine), and the same through a share ID by [the sharing acceptance](./resources/resources.md#^rs-ac-sharing), whose browser holds only the viewer's token while it loads the producer's artifact. An artifact's [store and share link](../../specs/product/artifacts.md#^af-store-share) are walked by those acceptances and [the share-command walk](./resources/resources.md#^rs-ac-share-cli), which reads both in the artifact's record. That deleting an artifact removes its share link and leaves its store, under [deletion](../../specs/product/artifacts.md#^af-delete-semantics), is walked through `tv delete-artifact` by [the recovery walk](./resources/resources.md#^rs-ac-recovery) and the share-command walk, and proven for every deletion path at the server by [the artifact-deletion contract](../arch/resources/index.md#^rs-arch-t-artifact-delete), which also covers bindings with the flag on; the frame-menu walk [#^af-ac-delete](#^af-ac-delete) reaches the same server deletion and adds no store check. That [a record is saved durably](../../specs/product/artifacts.md#^af-record-saved), with an outcome reported as unknown when its save cannot be confirmed, is the resource architecture's [write-order](../arch/resources/index.md#^rs-arch-t-write-order) and [uncertain-save](../arch/resources/index.md#^rs-arch-t-uncertain-save) contracts over the record writer, since no test can observe a real disk's durability or stage its failure.

Coverage relationship: fresh loading after a channel switch is crossed by [arch/artifact-frame/reload-navigation.md#^rn-ac-persist-browser](../arch/artifact-frame/reload-navigation.md#^rn-ac-persist-browser), whose real-browser case removes every frame while another channel is current and observes a newly loaded frame on return. Its history restoration is reload-navigation's promise; this spec adds no second channel-switch walk. Rearrangement continuity is deliberately not promised, so it creates no assertion.

Browser demo mode ([#^af-demo-mode](../../specs/product/artifacts.md#^af-demo-mode)) is proven by two Chromium acceptance walks, with a routing contract for the breadth of which artifacts it reaches. Shared declaration for the two walks: the outer boundary is Chromium driving the production app against a really-running server launched with the server-home hook above; the external page is a two-page HTML fixture served by a local HTTP server on an origin other than the Television server's, never a public site; the external page artifact is created through the production API; the default motion override is the only mock. Playwright reads the cross-origin frame's document to observe which fixture page is shown.

- **Acceptance** (shared demo-mode walk): with no marker file, the external page artifact's frame shows the unsupported-URL error page. After the marker file is created and the app is reloaded, the frame's document is the fixture's first page at its own URL, the frame shows no Back or Forward control, and the artifact icon is a button named by [content.yml#return_aria_label](../../specs/ui/app/artifact-frame/content.yml#return_aria_label). After the marker file is deleted and the app is reloaded again, the frame shows the unsupported-URL error page and the icon is not a button — *(covered by test: `packages/web/test/e2e/browser-demo-mode.test.ts` "the home-directory marker turns direct external pages on and off at app load (^af-ac-demo-mode)")*. ^af-ac-demo-mode
- **Acceptance** (shared demo-mode walk, marker present): following the fixture's link shows its second page; pressing the artifact icon shows the first page again. Following the link again and reloading the app shows the first page. Following the link once more, switching to another channel, and returning shows the first page. Back and Forward remain absent throughout — *(covered by test: `packages/web/test/e2e/browser-demo-mode.test.ts` "the artifact icon, an app reload, and a channel round trip each return to the original page (^af-ac-demo-return)")*. ^af-ac-demo-return
- **Contract** (the production artifact-frame view under jsdom with an authored external page artifact and a fake application service posing demo mode on — mocks that forfeit real document loading to [#^af-ac-demo-return](#^af-ac-demo-return); theme-change and artifact-content-change events are injected on that service): neither event reassigns the demo page's frame `src`, which stays the artifact's own URL — *(covered by test: `packages/web/test/artifact-view.test.ts` "browser demo mode artifact frame > leaves a demo-mode page's URL untouched through theme and content change events (^af-ac-demo-untouched)")*. ^af-ac-demo-untouched
- **Contract** (the production routing functions `artifactRenderRoute` and `artifactDocumentRoute` over authored artifact records and recorded current URLs; no mocks): with demo mode on in a browser, `http:` and `https:` artifact URLs that are not Television artifact addresses route to a direct iframe at the artifact's own URL, including a URL on the Television host itself; a Television artifact address keeps the shared-artifact route both on another host and on the connected Television host; a non-web URL keeps the unsupported-URL page. Path and Markdown artifacts, a Television-served artifact whose recorded current URL is an external web page, and every artifact in the desktop app route identically with demo mode on and off — *(covered by tests: `packages/web/src/artifact-dispatcher.test.ts` "browser demo mode routing", all four cases)*. ^af-ac-demo-scope

Coverage relationship: the two walks cross the real server's marker-file check, its delivery to the browser, routing, and frame rendering, and compose with [#^af-ac-demo-scope](#^af-ac-demo-scope), which carries the classification and routing breadth off the walked path, and [#^af-ac-demo-untouched](#^af-ac-demo-untouched), which keeps Television's own reload triggers away from the page. The walks reach the server through the development proxy, so app and server share an origin; the flag route's cross-origin CORS handling is code-authoritative and covered by `packages/server/test/endpoints.test.ts` ("GET /demo-mode answers a cross-origin browser client" and the protected-route preflight list). That demo pages cannot forward the navigation chord or feed theme pointer effects is carried by the bridge's non-participation assertions [arch/artifact-frame/artifact-bridge.md#^ab-ac-demo-inert-seam](../arch/artifact-frame/artifact-bridge.md#^ab-ac-demo-inert-seam) and [arch/artifact-frame/artifact-bridge.md#^ab-ac-demo-inert-host](../arch/artifact-frame/artifact-bridge.md#^ab-ac-demo-inert-host). A site that refuses framing is outside Television's behavior, since Television only leaves the browser's own outcome in place, and orders no test. Which views show the return button, and what pressing it requests, are the frame's contracts at [ui/app/artifact-frame/index.md#^af-ui-ac-return-scope](../ui/app/artifact-frame/index.md#^af-ui-ac-return-scope) and [ui/app/artifact-frame/index.md#^af-ui-ac-frame-actions](../ui/app/artifact-frame/index.md#^af-ui-ac-frame-actions).
