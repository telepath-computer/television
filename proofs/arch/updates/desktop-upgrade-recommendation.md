# Desktop upgrade recommendation — proof

Proves [specs/arch/updates/desktop-upgrade-recommendation.md](../../../specs/arch/updates/desktop-upgrade-recommendation.md).

## Coverage model

The production thresholds are checked directly without version hooks: the recommendation is `1.4.0` and the required floor is `1.3.1`. With those values, apps installed from npm at `1.3.1` or later pass the gate and receive the recommendation, and the [gate proof's floor contract](./desktop-upgrade-gate.md#^updates-t-themes-desktop-floor) runs representative shells through both production decisions. The decision takes no platform input, so one version selects the same apps on every platform. That every npm desktop release is 1.3.x or earlier and every downloaded release is 1.4.0 or later is a fact about what Television has released ([desktop app](../../../specs/product/desktop-app.md#^desktop-npm-package)), which no test observes.

Decision and presentation contracts cover eligibility, precedence, dismissal, the bell, the absence of a prompt and the absence of telemetry. A real-browser seam renders the fixed body, with its download link and installation steps, through the markdown pipeline, with Later as the only action. The product's real-Electron journeys ([recommendation](../../product/update-notifications.md#^ac-desktop-rec), [precedence](../../product/update-notifications.md#^ac-desktop-rec-precedence)) run a shell reporting an npm release against a server that advertises the production floor, and open the body's download link through the desktop app's external-link handling. The decision contract pins the recommendation at `1.4.0`, the value the spec keeps it at.

## Test hooks


This module adds no test hook. Its real-Electron acceptance paths reuse `TV_TEST_MODE=true` plus `TV_TEST_DESKTOP_APP_VERSION`, the shell-version hook owned by [desktop-upgrade-gate.md#^hook-shell-version](./desktop-upgrade-gate.md#^hook-shell-version). The hook changes the page parameter that both mechanisms consume and carries the same declared `app.getVersion()` forfeit; the unhooked shell-version seam remains shared proof of production provenance.
