*How the interactive Markdown table source contracts are proven through the real editor and a captured host-content boundary.*

# Markdown tables — proof

Proves [specs/arch/artifact-frame/markdown-tables-buffer.md](../../../specs/arch/artifact-frame/markdown-tables-buffer.md).

## Coverage model

These contracts adopt existing browser coverage as inherited evidence. Chromium runs the real Markdown view, parser, forked widgets, source mapper, transaction filters, and editing history. Source-preservation cases compare the complete root document and capture emitted update-content messages, so a visually unchanged widget cannot conceal a source rewrite or save.

The content bridge is mocked: fixtures deliver initial/remote content, acknowledge saves, or reject one to exercise rollback. This proves the document-side source/save boundary, not server persistence, filesystem writes, or delivery through a real parent frame. Those surrounding mechanisms remain outside this buffer's authority. Authored Markdown fixtures cover compact and unbordered tables, whitespace, escaped pipes, ragged/overflow cells, edge breaks, document edges, and a long document with delayed parsing. Link tests capture navigation messages and replace window.open; they prove handler selection and requested destinations, not opening a real browser context. The [UI proof](../../ui/markdown-editor/index.md#^md-table-t-interactions) owns clickable labels and interaction gestures.

Alignment, structural menu operations, and widget full-table paste converge on the same table-to-root synchronization, which replaces only the mapped table span. Structural boundary cases exercise that shared write boundary; the root-prose paste case is not evidence for widget full-table paste. Structural serialization is deliberately not lossless. Existing menu/history cases exercise its source write and surrounding content; they make no retention claim for overflow cells or edge breaks. Unsupported nested-table syntax and server-rendered Markdown receive no assertion here.

## Test hooks

- The Markdown view's `window.__cmView` exposes the root CodeMirror view for document/selection observation and setup dispatches; production users interact through the editor.
- Tests supply `window.__televisionContentBridge` to capture update-content messages and deliver content/replies; production uses the host content bridge.
- Link tests replace `window.open` and capture navigation-request messages instead of creating browser contexts or navigating the parent.

## Assertions

- **Inherited browser contract:** for [passive source preservation](../../../specs/arch/artifact-frame/markdown-tables-buffer.md#^mt-source-preservation), initial and remote noncanonical content, root/cell selection, rejected-save rollback, and undo/redo retain exact source except for the requested history change and produce no autonomous save. Real editor code runs against the mocked host bridge described above. The UI proof's [edge-navigation contract](../../ui/markdown-editor/index.md#^md-table-t-edge-navigation) carries the same source and save checks for table-edge navigation, including tables at document edges — *(covered by inherited tests: `packages/view-markdown/test/e2e/table-source-preservation.spec.ts`, “viewing and remote replacement render noncanonical tables without changing or saving source”, “rejected intentional edits roll back once and remain idle without autonomous save attempts”, “intentional cell edits replace only the table and undo remains byte preserving after selection”, and the root select-all/raw-caret fixture cases)*. ^mt-t-passive-source

- **Inherited browser contract:** for [intentional edits](../../../specs/arch/artifact-frame/markdown-tables-buffer.md#^mt-intentional-edits), full-source comparisons establish changed-cell replacement, retained untouched cells/overflow/edge breaks/whitespace and boundaries, missing-cell insertion, escaped-pipe mapping, first-header focus, and restored mapping after structural undo/redo. The mocked bridge captures intentional saves — *(covered by inherited tests: `packages/view-markdown/test/e2e/table-source-preservation.spec.ts`, “ordinary cell edits retain overflow cells and edge breaks in other cells”, “editing a missing cell inserts its delimiters without replacing other source”, escaped-trailing-pipe and first-header fixture cases, “editing the first of multiple missing cells retains the clicked column”, “ordinary edits immediately above and below a table preserve its boundaries”, “structural undo and redo restore source mapping before editing the restored third column”, and “intentional cell edits replace only the table and undo remains byte preserving after selection”)*. ^mt-t-intentional-source

- **Inherited browser contract:** for [structural editing's retained boundaries](../../../specs/arch/artifact-frame/markdown-tables-buffer.md#^mt-structural-limit), explicit menu operations update/save the table and structural undo/redo restore source around it. Canonical formatting and loss of extra internal content are permitted, not required outcomes — *(covered by inherited tests: `packages/view-markdown/test/e2e/tables.spec.ts`, “row and column menu changes save the updated source”; `packages/view-markdown/test/e2e/table-source-preservation.spec.ts`, “structural undo and redo restore source mapping before editing the restored third column”)*. ^mt-t-structural-source

- **Inherited browser contract:** for [link routing and source preservation](../../../specs/arch/artifact-frame/markdown-tables-buffer.md#^mt-links), table links select the shared handlers, refresh with document replacement, keep local-only URLs inert, and preserve source/caret offsets. Navigation messages and window.open are captured as described above; source-preservation coverage composes with [passive-source evidence](#^mt-t-passive-source) — *(covered by inherited tests: `packages/view-markdown/test/e2e/links.spec.ts`, “table links render and use the same navigation and editing gestures”, “table links refresh after document replacement and preserve surrounding text”, “clicking after rendered table links edits the corresponding source position”, “mixed table text stays current through repeated source edits”, and “table links keep browser-local URLs inert”)*. ^mt-t-link-routing

- **Inherited browser contract:** for [discovery without normalization](../../../specs/arch/artifact-frame/markdown-tables-buffer.md#^mt-discovery), noncanonical tables render on load/remote replacement; scrolling to a newly parsed offscreen table after a prior prose edit renders it without a caret move, source rewrite, or extra save. This is an eventual-rendering assertion, not a parser-latency or additional-syntax guarantee — *(covered by inherited tests: `packages/view-markdown/test/e2e/table-source-preservation.spec.ts`, “scrolling to a lazily parsed table after an earlier edit renders without formatting or saving it” and “viewing and remote replacement render noncanonical tables without changing or saving source”)*. ^mt-t-discovery
