# Artifact bridge — proof

Proves [specs/arch/artifact-frame/artifact-bridge.md](../../../specs/arch/artifact-frame/artifact-bridge.md).

## Coverage model

Coverage declarations are carried inside the migrated assertion blocks below.

## Test hooks


Shared-artifact acceptance tests exercise the real `HEAD` request, `ETag` comparison, backoff, bridge notification, and host reload path with a shorter cadence. Browser tests construct the producer `Server` with `testArtifactPollCadence: { normalMs, slowMs }`; that option is serialized into the producer's injected bridge and is absent from ordinary server construction. Electron tests pass `TV_TEST_ARTIFACT_POLL_NORMAL_MS` and `TV_TEST_ARTIFACT_POLL_SLOW_MS` to the desktop process; the preload honors both values only when `TV_TEST_MODE=true`. Both values must be finite positive numbers and `slowMs` must be at least `normalMs`; otherwise the production 5s/15s cadence applies.

The hook changes scheduling only. It does not replace a production mechanism, so acceptance coverage still crosses the real server, browser or webview, bridge transport, and reload seams.

## Assertions

### Acceptance criteria

The assertions use five declared harnesses:

- The **host contract harness** mounts the real artifact-frame view under jsdom with authored artifact records, then supplies synthetic `MessageEvent`, webview lifecycle, and IPC events. The iframe window or webview peer and its transport are mocked; these tests cover host handling but forfeit the real browser or Electron handoff, which the seam and acceptance assertions below cross.
- The **browser-bridge contract harness** runs the real `installBridge` against a framed jsdom `Window`, with authored DOM, keyboard, pointer, navigation, and lifecycle events. Parent `postMessage`, `fetch`, and timer control are mocks when used; the harness covers the producer side but forfeits real browsing-context delivery, network transport, and browser scheduling.
- The **preload contract harness** imports the real Electron preload under jsdom with authored lifecycle and input events. A fake `ipcRenderer`, fake `fetch`, and timer control replace Electron IPC, network transport, and browser scheduling when used; real-webview assertions below carry those crossings.
- The **browser seam harness** drives a real browser and iframe across real `postMessage`. A test may serve an authored document through Playwright routing; that route is a mock of document delivery and earns no server-injection coverage, which the real-HTTP proxy assertion carries.
- The **shared-artifact acceptance harness** drives either a real browser or the real Electron app against running producer and consumer servers with temporary artifact files. It uses the scheduling-only poll-cadence hook described above and no mock on the content-change, bridge, transport, reload, or rendered-result path.

Readiness assertions observe lifecycle state, never shielding, pointer suspension, or appearance.
