*How the promises in Telemetry property derivation are proven.*

# Telemetry property derivation — proof

Proves [specs/arch/telemetry/derivation.md](../../../specs/arch/telemetry/derivation.md).

## Coverage model

The inventory tuple is derived from YAML under [the bundled generation proof](../themes/bundled-installation.md#^bundled-t-manifest-generation). Pure contract tests use authored inputs and production classifiers, without mocks or test hooks. They cover classification breadth, including active-theme declarations, exact-ID consent, and stored appearance. Real validated packages and committed store state reach those classifiers through the [emitter seams](./emitters.md#^t-theme-settings-refresh), while [product acceptance](../../product/telemetry.md#^ac-theme-adoption) crosses HTTP and websocket transport. Script execution is outside configured-use telemetry's claim.

## Assertions

### Test assertions

All assertions use the pure derivation contract harness: authored artifacts, layouts, address sets, user-agent strings, server config, theme state, and skill paths are fixtures passed to the real classifier functions. There are no mocks or test hooks. The real attachment handoff is [emitters.md#^t-emit-hooks](./emitters.md#^t-emit-hooks).

- **Contract** (table-driven artifact classifier): folder, HTML, Markdown, and other paths plus artifact-proxy, localhost, tailnet, and third-party URLs derive the documented classifications without returning their source strings — *(covered by inherited tests: all ten table rows in `packages/server/src/telemetry/derivation.test.ts` “telemetry artifact derivation”)*. ^t-artifact-classify
- **Contract** (table-driven target `TabPage` classifier with authored page orders, artifact sets, stored sizes, and full-screen mode as fixtures; no mocks or test hooks): page reorder yields `tab_reorder`, while unchanged order, page-size-only change, artifact add/remove, regrouping, and a full-screen-only change yield no reorder classification — *(covered by `packages/server/src/telemetry/derivation.test.ts` “telemetry page reorder derivation”)*. ^t-layout-classify
- **Contract** (table-driven retained-page matcher over authored layouts): one or several full-screen transitions return their committed booleans, including alongside reorder, while unchanged presentation and page add/remove return no transitions — *(covered by `packages/server/src/telemetry/derivation.test.ts` “telemetry page full-screen derivation”)*. ^t-full-screen-classify
- **Contract** (table-driven ordered pin-list classifier): pin, unpin, reorder, and replacement return the documented classification and committed count, while an unchanged list returns no classification — *(covered by `packages/server/src/telemetry/derivation.test.ts` “telemetry channel pins derivation”)*. ^t-pin-classify
- **Contract** (binding classifier): representative address sets produce each loopback, all-interfaces, tailnet, and other-specific boolean, including combinations and IPv6 loopback — *(covered by inherited tests: all six “telemetry binding derivation” rows in `packages/server/src/telemetry/derivation.test.ts`)*. ^t-binding
- **Contract** (client classifier): representative browser and Electron user agents derive platform, vendor, and coarse major version; mobile platforms and an unknown user agent map correctly; composing metadata adds app and desktop version without emitting the raw user agent — *(covered by inherited tests: all ten “telemetry user-agent derivation” cases in `packages/server/src/telemetry/derivation.test.ts`)*. ^t-ua
- **Contract** (config classifier): default and custom port, default and custom home, enforced and unenforced auth, and CLI/daemon launch modes derive correctly. The home is `default` when its absolute path equals `.television` in the operating-system home directory and `custom` for any other path, and the result is reported under the `storage_path` key. The classifier receives only the resolved path, so how `--home` or `~/.tv-home` selected it cannot change the result; [the home resolver's contracts](../cli/index.md#^cli-home-pointer-contract) prove that a pointer naming `.television` resolves to that path — *(covered by inherited tests: all three “telemetry server config derivation” rows in `packages/server/src/telemetry/derivation.test.ts`)*. ^t-config
- **Contract** (agent classifier): every named harness token, generic `.agents` directory, interactive selection, and unrecognized path produce the documented agent type — *(covered by inherited agent-type tests in `packages/server/src/telemetry/derivation.test.ts`)*. ^t-agent-type
- **Contract** (pure harness-name normalizer): known and novel product names retain their text after trimming and lowercasing, including Claude Code without aliasing; blank/absent values are omitted. This is intentionally an open-ended string, covered by inherited test: `packages/server/src/telemetry/derivation.test.ts` “normalizes open-ended installed-by harness product names”. ^t-installed-by-agent
- **Contract** (theme classifier): the null theme derives `none`, every theme ID in the generated inventory tuple derives itself, and any other active theme ID derives `custom`, all with the registry count and without returning a user-authored theme name. The fixture covers an edited package at a bundled theme ID and an ID removed from the bundled set, which derives `custom` — *(covered by inherited tests: the “telemetry theme derivation” cases in `packages/server/src/telemetry/derivation.test.ts`)*. ^tel-t-theme
- **Contract** (current-settings classifier, authored validated-entry and consent fixtures, no mocks): the six-field snapshot includes explicit false values for None, missing entries, and absent/false declarations; each true iframe declaration is independent of main consent; main enablement requires both its true declaration and consent for the active exact ID, with inactive-ID consent having no effect. Each stored appearance preference passes through unchanged. The result contains only the six declared keys and values, never fixture names, IDs outside the bundled vocabulary, or a consent list. A compact table proves [settings derivation](../../../specs/arch/telemetry/derivation.md#^theme-settings-derivation) without a full cross-product of independent flags — *(covered by tests: `packages/server/src/telemetry/derivation.test.ts`, “TV-755 theme settings derivation”)*. ^t-theme-settings
- **Contract** (all classifiers composed): no classifier output contains a path, URL, title, channel name, theme name, raw user agent, or other user-generated string; outputs are enumerations, booleans, integers, versions, and open-ended harness product names — *(covered by tests: `packages/server/src/telemetry/derivation.test.ts` “returns only classifications, integers, and versions”)*. ^t-no-ugc-outputs
- **Contract** (pure classifier, authored version strings, no mocks): strict SemVer core versions retain their numeric triple; prerelease/build metadata is discarded; whitespace, leading `v`, invalid numeric identifiers, paths, emails, and malformed versions become `0.0.0`. Proves [version derivation](../../../specs/arch/telemetry/derivation.md#Behavior) — *(covered by tests: `packages/server/src/telemetry/derivation.test.ts`, “classifies strict semantic versions without private labels”)*. ^t-version-classification
