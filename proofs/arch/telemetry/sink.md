*How the promises in Telemetry sink are proven.*

# Telemetry sink — proof

Proves [specs/arch/telemetry/sink.md](../../../specs/arch/telemetry/sink.md).

## Coverage model

Ordinary and isolated release builds cross the real bundler and compiled skills-install action with real copied skill files. Their analytics transport is intercepted before any network access, so production routing is observed without sending to production. The live test-project suite proves the actual delivery and stored privacy outcome. Request contracts cover both collectors, and the other buffer/lifecycle seams below retain their declared boundaries. No test changes PostHog settings or historical data.

## Test hooks

`CreateTelemetryRuntimeOptions.sink`, `SkillInstalledTelemetryOptions.sink`, and `ServerTelemetryOptions.sink` let tests replace outbound delivery with a `TelemetryRuntimeSink` — anything with `enqueue` and an optional `shutdown` — that records what it receives. The replacement receives fully built events after identity, suppression, session attribution, and event construction. Under the testing policy's [mocking policy](../../../specs/arch/testing-policy.md#Mocking policy), it forfeits sink buffering and PostHog delivery.

`TelemetrySinkOptions.transport` (the transport, so a test can make sends succeed, fail, or hang), `TelemetrySinkOptions.maxBufferSize` (the buffer bound), `TelemetrySinkOptions.autoFlush` (whether flushes are scheduled automatically), `PostHogTransportOptions.fetchImpl` (the `fetch` the transport calls), and `TelemetrySink.pendingCount()` (how many events are queued) are available to tests.

Routing cases isolate the home from the host marker using explicit booleans, captured-home directories, or HOME-only child environments.

## Assertions

### Test assertions

The transport contract replaces `fetch` with a request recorder, so it proves HTTP request construction and project choice but forfeits network and PostHog ingestion. The buffer contract injects a deterministic transport that records, rejects, or later succeeds; it proves only buffer and flush behavior. The runtime project-selection seam starts a real server and default sink but replaces global `fetch`, forfeiting the final network hop to the integration surface. Temporary homes and marker files are fixtures. Source lifecycle routing cases are minimally updated to stub the baked marker and restore it; they forfeit compilation to the real build seam. The build seam runs the real CLI build and inspects its final bundle with no network or secrets.

The explicit-test PostHog harness uses the real HTTP transport, sandbox project, read API, uniquely generated identities, temporary server data, and, where stated, the real host service manager. It has no sink or transport mock. It is excluded from routine runs and requires the declared read-key preflight. Persisted-daemon construction is replaced only as declared by [product/telemetry.md#^ac-persist-auth-install](../../product/telemetry.md#^ac-persist-auth-install).
