# Weather artifact template — proof

Proves [specs/arch/templates/weather.md](../../../specs/arch/templates/weather.md).

## Coverage model

Package contracts read the real bundled manifest, seed, page files, icon and README. The generic [template proof](./index.md) owns creation-time schema enforcement, copying, display-option precedence and independent stores. [Bundled installation](./bundled-installation.md) owns build membership and boot replacement. The assertions here establish the Weather values supplied to those shared paths.

Pure contracts exercise the configuration and saved-forecast parser, request builder, Open-Meteo response normalizer, request eligibility, forecast selection, cache-transaction updater, display windows, rounding and elapsed age used by the copied page. `test/fixtures/weather/open-meteo/current-success.json` and `current-success-fahrenheit.json` are the refreshable San Francisco Celsius and Fahrenheit successes; `kolkata-2026-10-27.json` and `new-york-dst-2026-10-27.json` are immutable, date-pinned time-zone successes; and `error-latitude-out-of-range.json` is an immutable HTTP-error response. Each records the exact request, response status and CORS header alongside the unmodified provider body. Edited copies vary one relevant response field for mapping and failure breadth. Real-clock browser walks copy an everyday success and shift every UNIX timestamp in `current`, `hourly` and `daily` by the same whole number of days, chosen so more than 24 hourly entries remain after the actual current instant. This keeps every entry's relative position and each daily value on local midnight under the response's fixed offset; all other captured values and headers stay unchanged. Those are fixtures, not replaced page code; the contracts do not claim HTTP, browser CORS, store or rendered-page coverage.

Default browser tests run the copied page in Television's real sandbox against a running server, resource SDK and JSON store. They intercept every `https://api.open-meteo.com/**` request and script its captured response, delay or failure. That interception mocks the provider and public network, forfeiting the live endpoint, current provider response, provider timing and availability. The browser still makes the production fetch and applies real CORS checks to the captured `Access-Control-Allow-Origin` header. An unexpected provider method, URL, query or disposition fails the test, and every other external request is blocked.

One opt-in browser test, excluded from CI and default verification, crosses the real browser-provider seam from Television's opaque-origin sandbox. It proves the live endpoint, current browser CORS path and response acceptance for both temperature units at the time it runs, and may refresh only `current-success.json` and `current-success-fahrenheit.json`. The error, Kolkata and New York fixtures stay fixed. Developers run this test after any change to the request builder, response normalizer or fetch code and before release. The live test does not prove the provider's terms or limits, future compatibility or availability, or the desktop `Origin` and `Referer` path. The release gate remains human sign-off, not a test result.

The [Weather UI proof](../../ui/templates/weather.md) owns visible labels, responsive composition, placeholder states, access and recovery, attribution and conformance. It shares the primary creation/fetch/save walk with this proof. The first-party condition drawings and Toolbox icon need no third-party notice. The warning and spinner copied from the foundation use Phosphor artwork; [licensing coverage](../licensing.md#^licensing-t-weather-icons) owns the asset record and generated package notice.

## Test hooks

No production test hook is required. Contract tests call the same production parsing, request, normalization and selection modules the page imports.

Playwright may control the browser clock. Production uses the browser clock. Clock control forfeits real elapsed scheduling, not the page's timer callback, request decisions or time-zone calculations. In the repository's Chromium, an installed Playwright clock advances both an ordinary `setTimeout` and `AbortSignal.timeout`. The timeout acceptance installs the clock before page code, advances it beyond 10 seconds and observes the request abort without requiring either timer mechanism.

For the visibility acceptance, an installed Playwright helper defines consistent configurable values for `document.visibilityState` and `document.hidden` on the real document, then dispatches `visibilitychange` after changing them. This mechanism was checked in the repository's Chromium: the document reported `hidden` with `hidden === true`, then `visible` with `hidden === false`, and received both events. It mocks native browser Page Visibility delivery and forfeits that browser integration, but it does not replace the page's event handler, request check or scheduler. Automation-created Chromium tab activation did not change `document.visibilityState`, so the proof does not rely on it.

Browser tests intercept the provider at the network boundary as declared above. They use temporary Television homes, real stores and authored configuration or saved-cache fixtures. A shared forwarding proxy may sever an established Television connection and refuse reconnection without fabricating store values or access changes; access changes come from a real share page. The proxy forfeits only the deliberately severed transport. The opt-in live test removes provider interception for the two exact San Francisco requests only.
