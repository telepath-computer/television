# Document artifact template — proof

Proves [specs/arch/templates/document.md](../../../specs/arch/templates/document.md).

## Coverage model

Package contracts read the real bundled manifest, seed, page, icon, committed editor files, notices, and README. A source contract checks that the Markdown file view and packaged Markdown editor build use the same editor implementation. A real build seam runs the packaged Markdown editor check and compares fresh output with the committed files; the licensing proof owns the record and notice inputs checked in the same run, and the Markdown-editor UI proof relies on that licensing seam to keep the committed stylesheet current. A build-boundary contract checks that product builds do not rebuild the packaged Markdown editor or write into the source template folder. The [bundled-installation build seam](./bundled-installation.md#^templates-install-t-build) carries the byte-identical copy from that committed source folder through the server and CLI builds. Browser contracts load the committed packaged Markdown editor files in an authored ordinary document. The document is a fixture, and test-written `onSave` callbacks replace the page and resource SDK; this forfeits the artifact sandbox and store to the real-stack acceptances.

The store acceptances run Chromium against a spawned production CLI server, its installed and copied Document package, the resource SDK, and a real JSON store. The new-artifact walk proves that the copy carries its editor and notices and that the editor works without any Television editor route. Authored initial store values are fixtures. A forwarding proxy carries the real protocol bytes and can record, delay, refuse, or sever their delivery; this replaces only uncontrolled network timing and failure, forfeiting natural transport failure while retaining the production SDK, server, messages, and persistence. In the live-replacement and access-loss cases, Playwright pauses the page clock after the proxy has captured the real server message, delivers that message after one input event, and advances past the save pause; this forfeits natural timer scheduling while proving the incoming message cancels the pending save regardless of test-runner delay. The code-authoritative saving-status regression likewise advances the page clock around the delayed notice. The link acceptance opens an owner artifact in the application, assigns that artifact iframe the read-share URL, and checks the retained sandbox attribute, opaque origin, and insecure context before using the editor; the swap forfeits only the application action that would assign the same share URL. The [resource SDK proof](../resources/sdk.md) carries direct browser-to-server transport. The default CSS-motion override forfeits only motion, which no assertion claims.

The shared [link-classifier contract](../artifact-frame/artifact-bridge.md#^ab-ac-link-classifier) proves external and modifier-click dispositions at the shared navigation-request boundary, while the Markdown file view's inherited link tests prove its gestures. Application-link coverage is adjacent composition, not an exact template walk. The inherited editor tests prove its scripted `window.location.href` application-link handoff outside a sandbox. [Browser application-link acceptance](../../product/artifact-navigation.md#^ac-application-links-browser) proves native-anchor handoff and repeated prompting inside the standard artifact sandbox. The real-stack template acceptance proves that the packaged Markdown editor operates in that sandbox and crosses relative navigation, but it does not activate an application link there. No test repeats operating-system protocol registration solely for this template.

In the desktop app, the webview preload supplies `__televisionContentBridge`: the editor sends web navigation through `postToHost` and application links through `openApplicationLink`, and the trusted channel handles both for the webview the app shows. The [webview navigation contract](../artifact-frame/reload-navigation.md#^rn-ac-current-route) and [Electron application-link seam](../artifact-frame/artifact-bridge.md#^ab-ac-application-link-electron-seam) cover those parts with ordinary artifact webviews and the Markdown file view; no test repeats their composition in a bundled Document template webview.

The [Markdown editor UI proof](../../ui/markdown-editor/index.md) owns colour delivery and table interactions. Existing editor browser suites retain the shared implementation's tables, task lists, Markdown gestures, undo history, punctuation treatment, and file-host binding; the source/build seam below proves that both builds use that implementation, and the internal-mount contract exercises undo through the template boundary. Canonical-v2 compatibility is judged by implementation and visual review under frame/template UI conformance; automation proves the required sheet order and scope, and the new-artifact acceptance proves canonical v2 and the packaged Markdown editor load together. The icon contract below proves selection of the real first-party SVG; review of its saved 20-pixel renders on light and dark backgrounds judges the page, folded corner, text lines, scale, and stroke weight because path-level assertions cannot establish those visual meanings. [Template architecture](./index.md) owns general copying and seed creation, and [bundled installation](./bundled-installation.md#^templates-install-t-copied-artifacts) owns copied artifacts surviving installed-template changes. [Resource SDK](../resources/sdk.md) and [JSON store](../resources/json-store.md) own transport, optimistic values, rollback, and write ordering. A real uncertain-outcome refusal composes the internal-mount case where a matching authoritative value remains after its save rejects with the [resource SDK's browser transport](../resources/sdk.md) and the JSON store's [uncertain-write ordering](../resources/json-store.md#^js-arch-t-uncertain); the real-stack lost-acknowledgement acceptance instead walks disconnect rollback. [Licensing](../licensing.md#^licensing-t-markdown-editor-build) owns package and vendored-asset coverage and notice reproduction. The blank document's focus, the status shell's `Saving…` notice, loading without an editor, hiding the editor for unreadable data or a missing local editor script, read-only table selection and copying, the read-only Alt-click guard, and save-failure report checks are code-authoritative regressions, not policy assertions here.

## Test hooks

The Markdown file view exposes `window.__cmView` in development and production for its established browser and Electron tests. The packaged Markdown editor and page do not use that hook. The internal-mount browser fixture supplies test-written `onSave` callbacks. Real-stack cases use no editor-library hook and drive the public document surface.
