# Map artifact template — proof

Proves [specs/arch/templates/map.md](../../../specs/arch/templates/map.md).

## Coverage model

Package checks read the real Map source: its manifest, empty starting store, README guidance, canonical and local assets, vendored dependencies, and icon. A browser opens a Map artifact against a running server and real store while external Esri tile requests are aborted locally. That interception forfeits rendered-tile coverage but leaves the real copied page, Leaflet runtime, resource SDK, server, and store in the path. The browser exercises the empty store, live agent writes, filters, details, local controls, tolerant later values, disconnection, access loss, unreadable data, and recovery without page writes. The controllable proxy severs and restores the real browser connection for the disconnection case. Real share revocation produces the SDK `no-store` result. Restarting the real server over an authored damaged store file produces another terminal error, and a second restart over the restored file proves resubscription. The ordinary copy and default-display rules are covered by [template architecture](./index.md) and [layout creation](../layout/index.md#^ly-ac-create-appends); build membership and minimum versions are covered by [bundled installation](./bundled-installation.md). The architecture proof covers what the store means and what the page shows, omits, falls back to, or reports. Presentation remains code-authoritative under the [migration map](../../../specs/spec-migration.md), so this proof makes no appearance or conformance claim.
