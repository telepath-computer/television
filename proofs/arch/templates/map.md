# Map artifact template — proof

Proves [specs/arch/templates/map.md](../../../specs/arch/templates/map.md).

## Coverage model

Package checks read the real Map source: its manifest, empty starting store, README guidance, canonical and local assets, vendored dependencies, and icon. A browser opens a Map artifact against a running server and real store while external Esri tile requests are aborted locally. That interception forfeits rendered-tile coverage but leaves the real copied page, Leaflet runtime, resource SDK, server, and store in the path. The browser exercises the empty store, live agent writes, filters, details, local controls, tolerant later values, disconnection, access loss, unreadable data, and recovery without page writes. The controllable proxy severs and restores the real browser connection for the disconnection case. Real share revocation produces terminal loss of access. Restarting the real server over an authored damaged store file produces the other terminal error, and a second restart over the restored file proves recovery. The ordinary copy and default-display rules are covered by [template architecture](./index.md) and [layout creation](../layout/index.md#^ly-ac-create-appends); build membership and minimum versions are covered by [bundled installation](./bundled-installation.md). The page UI remains code-authoritative under the [migration map](../../../specs/spec-migration.md), so this proof makes no appearance or conformance claim.
