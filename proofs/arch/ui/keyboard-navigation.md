### Test assertions

Coverage relationship ([arch/testing-policy.md#^declaration-schema](../../../specs/arch/testing-policy.md#^declaration-schema)): movement semantics are proven by [product/keyboard-navigation.md](../../../specs/product/keyboard-navigation.md)'s acceptance assertions. The bridge owns the browser document's and Electron's native predicate and delivery matrices ([arch/artifact-frame/artifact-bridge.md](../../../specs/arch/artifact-frame/artifact-bridge.md), Keyboard forwarding). The tab strip's single tab-order stop and unmodified arrow behavior are proven by [ui/app/tab-strip/index.md#^tb-ac-keyboard](../../ui/app/tab-strip/index.md#^tb-ac-keyboard). This section proves the shell listener and the two common operation boundaries; it orders no rendered parity test — no screenshot, transition, or DOM comparison. None of these assertions claims motion, and no animation or transition override is used.

- **Contract** (the function that matches the shell chord over authored macOS, Windows, and Linux identities and authored keyboard-event records; no mocks or test hooks): option on macOS and ctrl on Windows/Linux return each arrow with no other modifier, including `repeat`. Unmodified arrows, the required modifier combined with Shift or any other extra modifier, composing keydowns, non-arrow keys, and the other platform modifier alone return no match — *(covered by `packages/web/src/services/application-navigation.test.ts` “shell navigation chord predicate (^kbn-ac-shell-predicate) > matches only the platform modifier and physical arrows, including repeat”)*. ^kbn-ac-shell-predicate
- **Seam** (runtime platform detector → production shell predicate, crossed in a real browser using its actual platform identity; an authored keyboard-event record is the fixture; no mocks or test hooks): the detector's value feeds the predicate and the current platform's matching record returns its arrow — *(covered by `packages/web/test/e2e/keyboard-navigation.test.ts` “shell navigation door (^kbn-ac-platform-seam, ^kbn-ac-shell-door) > uses the real platform chord in a focused chrome field and leaves a non-match native”)*. ^kbn-ac-platform-seam
- **Seam** (shell key listener → navigation handler, crossed through real DOM event delivery in the same real-browser shell case; authored page state, a focused app-chrome text field, and body focus after a successful move are fixtures; a call-through observer records handler entry and replaces no behavior; no mocks or test hooks): one matching horizontal chord cancels its native default and reaches the handler once despite the text field, a second matching chord delivered to body focus reaches it once without refocusing a root descendant, and a representative non-match remains native and does not reach it — *(covered by `packages/web/test/e2e/keyboard-navigation.test.ts` “shell navigation door (^kbn-ac-platform-seam, ^kbn-ac-shell-door) > uses the real platform chord in a focused chrome field, continues from body focus, and leaves a non-match native”)*. ^kbn-ac-shell-door
- **Seam** (tab selection callback and navigation handler → production page-selection operation, crossed through their real event/callback paths in a DOM harness; authored channels, pages, and initial selection are fixtures; a call-through spy records operation entry and executes the real in-memory mutation unchanged; no mocks or test hooks): a pointer click on a tab and a horizontal chord step each enter that same operation with the target page — *(covered by `packages/web/test/e2e/keyboard-navigation.test.ts` “one application navigation operation > tab release and horizontal chord enter selectPage once with the same target (^kbn-ac-one-operation)”)*. ^kbn-ac-one-operation
- **Seam** (channel-row selection callback and navigation handler → production focused-channel operation, crossed through their real event/callback paths in the same DOM harness; authored channels, order, and initial focus are fixtures; a call-through spy records operation entry; a recording server adapter beyond that operation is a mock, greenlit here, and forfeits the real shared-state write to [product/keyboard-navigation.md#^tp-ac-chord-vertical](../../product/keyboard-navigation.md#^tp-ac-chord-vertical) and [product/channels.md#^ch-ac-focus-broadcast](../../product/channels.md#^ch-ac-focus-broadcast)): a pointer click on a channel row and a vertical chord step each enter that same operation with the target channel — *(covered by `packages/web/test/e2e/keyboard-navigation.test.ts` “one application navigation operation > channel-row release and vertical chord enter focusChannel once with the same target (^kbn-ac-one-operation-focus)”)*. ^kbn-ac-one-operation-focus
