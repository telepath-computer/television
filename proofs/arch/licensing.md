# Licensing architecture — proof

Proves [specs/arch/licensing.md](../../specs/arch/licensing.md).

## Coverage model

Contract tests drive the generator and gate with authored inventories, manifests, configs, package trees, and expected output; those fixtures replace bundler discovery only for permutation breadth. Production seams run every shipping esbuild and Vite build, persist their real inventories, aggregate notices, and inspect the real committed asset manifest. The suite handoff then proves those inventories reach the ordinary licensing gate.

Folder notices are proven at the contract tier: fixture manifests drive the generator's folder output, the loader's `noticesFolder` validation, and the gate's staleness rule, and the real tree's committed Nord folder file is held current by the product's real-tree gate acceptance. The real-asset seam reads `scripts/licenses/assets.json` directly. It checks the three wallpaper identities, the allowlist including `LicenseRef-Unsplash`, Tokyo Night Apache text, all three photo attributions and license terms, and source/CLI/folder coverage using the existing notice-generation and staleness checks. It also checks the Tailwind component in Clouds, the source-only token demo record, and the live/frozen foundation paths and surfaces. Clouds and live/staging attribution comments identify Tailwind and its supplied copyright. Generated source and Clouds folder notices contain the complete recorded MIT text once, even though several records share it. Frozen payload bytes are not edited. Its path-membership checks keep the source inventory aligned with the frozen v1 font and component bundle plus the live copies, while notice and build assertions prove those records reach the declared surfaces. Product acceptance owns the user-facing source, browser, CLI tarball and desktop upload-directory outcomes; the desktop's [upload-directory check](../../specs/arch/licensing.md#^licensing-upload-assertions) is [its acceptance](../product/licensing.md#^licensing-ac-desktop-upload). [Where Electron's license files sit](../../specs/arch/licensing.md#^licensing-electron-built-app) is checked in the built Mac app by the desktop product's [recorded real-Mac run](../product/desktop-app.md#^desktop-ac-electron-license-files).

## Assertions

Shapes per the [testing-policy.md](../../specs/arch/testing-policy.md) declaration schema. The spine acceptance tests — including the real-tree gate pass, the per-input-class CLI tarball entries, the desktop upload directory, and the served browser notices — are owned by the [product proof](../product/licensing.md#assertions); the assertions here are the breadth behind them. The clean seam this composition leans on: the generator and gate consume the same persisted inputs (the [inventory root](../../specs/arch/licensing.md#^licensing-inventory-root)'s per-surface inventories, config, asset manifest) through one loading path.

- **Contract — generator.** Fixture metafiles, bundle-module lists, and package trees in, notices text out. Covers: input-path → containing-package mapping (including scoped and nested packages); [the ignored filter](../../specs/arch/licensing.md#^licensing-ignored-filter) — a fixture package matched by an exact pattern and one matched by a `@scope/*` pattern each leave no inventory record and no notices text, and a fixture whose every package is ignored yields no file at all ([existence rule](../../specs/arch/licensing.md#^licensing-notices-existence)), while one retaining a single handled package still yields a well-formed file; the [notice-resolution rules](../../specs/arch/licensing.md#^licensing-notice-resolution) — license-file case, config-`notices` case (a `cookie-signature`-shaped fixture: MIT declared, no license file, config-supplied text), and the **failure** when neither resolves; reproduction of a synthetic Apache package's `NOTICE` file; election application; vendored-asset folding per surface (including `skill:*` and `source`), including a component missing its notice text, one missing its license, and one naming an ignored package each failing the build; the [content rule](../../specs/arch/licensing.md#^licensing-notices-header) — the rendered file names the product and what the file is, contains no config `id` and none of this spec's field names as labels, and renders an asset-sourced and a bundler-sourced entry in the same shape, so neither betrays its origin; entry naming — a package-identity entry carries its name and version, a component without package identity carries its own `name`, and one with neither package identity nor a name is rejected; an asset naming an undeclared surface is rejected, and a plugin is rejected when constructed with an undeclared or non-inventory surface; [one entry per item](../../specs/arch/licensing.md#^licensing-entry-once) — the same name and version arriving from both an inventory and the asset manifest renders once, and a disagreement between them about license or notice text fails the build; [record dedupe](../../specs/arch/licensing.md#^licensing-record-dedupe) — combining inventories where one record carries a license file and the other does not keeps the one that does; deterministic output ordering; [folder notices](../../specs/arch/licensing.md#^licensing-folder-notices) — an asset naming a `noticesFolder` yields a `THIRD-PARTY-NOTICES.txt` in that folder rendered from its components under the same content rule, two assets naming one folder share one file, an asset without the field yields no folder file, and the loader rejects a `noticesFolder` that is absolute, escapes the repository, is missing, or is not a folder. The bundlers are absent — the fixtures are authored data, declared here. ^licensing-t-generator-contract
- **Contract — gate.** Fixture inventories and configs in, exit results out. Covers each failure rule in [gate behavior](../../specs/arch/licensing.md#^licensing-gate-behavior): disallowed license, unresolvable notice, election drift (via the recorded `offered` value), dead config entries per category ([dead-entry rules](../../specs/arch/licensing.md#^licensing-dead-entries) — including an entry whose package survives only in `node_modules` as dev tooling), an inventory-producing declaration whose inventory is absent from the root ([forward direction](../../specs/arch/licensing.md#^licensing-declared-forward) — the writer and the plugin refuse the opposite case at its source, so the gate has none to check), stale root notices, a [folder notices file](../../specs/arch/licensing.md#^licensing-folder-notices) that is stale and one that is missing, plus the passing case with elections applied. The [declared-dependency scan](../../specs/arch/licensing.md#^licensing-declared-scan) reads the `dependencies` of both the public CLI package and the private desktop workspace: a declared dependency under a disallowed license fails by name, one that is not installed fails, and neither a notice nor its own dependency tree is required or scanned. An ignored package cannot reach the gate, so no ignored package is gated; what the gate contract does cover for that config category is that an ignored pattern matching nothing in the current tree is **not** reported dead ([dead-entry rules](../../specs/arch/licensing.md#^licensing-dead-entries)), since the list is a standing scoping decision rather than a correction to an observed fact. A companion config-loader case proves the pattern grammar: exact and `@scope/*` forms load, and a bare `*`, a partial wildcard, a trailing-slash form, and an empty pattern are each rejected by name — *(covered by tests: the “license gate” cases in `test/repo/licensing-gate.test.ts` and the “licensing configuration” cases in `test/repo/licensing-config.test.ts`)*. ^licensing-t-gate-contract
- **Seam — esbuild wiring.** Parameterized over **both esbuild products**: a real full CLI build and a real desktop build each persist their surface inventory, proving the metafiles really flow from each `build.mjs` into the generator on the production build path, and each write a notices file where that surface has entries. The CLI's file carries entries for genuinely bundled packages (`express`); the desktop's carries the single package its bundles actually compile in (`@rupertsworld/event-target`), since its sources are otherwise workspace code, and `electron` and the workspace's declared `dependencies` load from outside the bundle — a one-entry file that exercises the same [existence rule](../../specs/arch/licensing.md#^licensing-notices-existence) from the populated side. Crossed once for real per product; package-level permutations stay in the generator contract tests. ^licensing-t-build-seam
- **Seam — Vite inventories.** Parameterized over **every shipping Vite build** (`web`, `view-markdown`, `tv-calendar`, `tv-tasks`): a real `vite build` persists its surface inventory and yields a final per-dist notices file exactly where the surface has entries. The web, markdown, and `tv-tasks` inventories each list a genuinely bundled package; `tv-calendar`'s framework-free bundle records no packages and emits no notices file. Every dist contains no raw inventory artifact ([no in-dist inventory](../../specs/arch/licensing.md#^licensing-vite-intermediate)), and inline `/*! @license` banners survive minification where present ([legal comments](../../specs/arch/licensing.md#^licensing-legal-comments)). ^licensing-t-vite-seam
- **Seam — aggregation.** The full CLI build's umbrella notices include entries sourced from the copied-in web inventory and the `tv-tasks` skill inventory, the copied `tv-tasks` directory retains its notices file, and the dependency-free `tv-calendar` directory has none; no copied skill carries a raw inventory artifact. This proves the [aggregation](../../specs/arch/licensing.md#^licensing-notices-placement) and [per-skill placement](../../specs/arch/licensing.md#^licensing-skill-notices) handoffs are wired. ^licensing-t-aggregation-seam
- **Seam — suite inventory handoff.** On the suite path (the [real-tree acceptance](../product/licensing.md#^licensing-ac-gate-passes)'s boundary), the `e2e:node` pre-build's two real product builds populate an inventory for every [declaration with `producesInventory: true`](../../specs/arch/licensing.md#^licensing-declared-surfaces) in the shared root, and the in-suite gate consumes them, asserted through the gate enumerating the surfaces it checked. This is the crossing the per-build seams cannot prove: the inventories survive their child build processes and reach the gate that enforces them. ^licensing-t-suite-seam
- **Seam — real asset records.** Reads the **real committed `assets.json`** (not a fixture) and asserts that every declared path exists; the Clouds record includes its CSS and wallpaper paths, Tailwind and both photo components, and `cli`/`source`/folder delivery; the Tailwind foundation record covers all live copies and frozen v1 with `web`, `view:markdown` and `source` delivery; the retained token demo has a source-only Tailwind record; Tailwind attribution comments open the Clouds and live/staging stylesheets, and its complete MIT text renders once in root and Clouds folder notices; the Hind record names the frozen v1 font, live v2 canonical font, web font, and foundation-spec font with no deleted v1 source/spec path; the Phosphor record names both the live icon source and frozen v1 component bundle; and the Nord record names the UI-spec stylesheet and its production copy, the `cli` and `source` surfaces, and the Nord theme folder as its `noticesFolder`, with both stylesheets opening with the [attribution comment](../../specs/arch/licensing.md#^licensing-theme-records). The Hind and Phosphor records appear in the root notices, CLI umbrella notices, and web dist notices, and the Nord record in the root notices, CLI umbrella notices, and its committed folder file, proving that the authoritative records exist and flow to every surface they declare — *(covered by `test/repo/licensing-config.test.ts` and the real build/gate cases in `test/node/licensing.test.ts`)*. ^licensing-t-real-assets-seam
- **Contract — manifest lint.** The extended `check-publishable` manifest rule fails on a fixture workspace manifest lacking `"license": "MIT"` and passes the real tree. ^licensing-t-manifest-contract
