# Nord

Nord brings the cool blue-gray colors of the [Nord palette](https://github.com/nordtheme/nord) to Television. It stays dark in both light and dark appearance settings.

Pale text and an icy cyan accent stand out against dark surfaces. A deeper, quieter background separates the content from the surrounding application, while warmer accent colors distinguish status and actions.
