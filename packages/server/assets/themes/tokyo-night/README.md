# Tokyo Night

Tokyo Night combines a dark city photograph with the blue and purple tones of the Tokyo Night palette. It stays dark in both light and dark appearance settings.

The city lights give the background texture, while dark translucent controls and blur keep the interface readable. Blue marks primary actions against cool, subdued surfaces.
